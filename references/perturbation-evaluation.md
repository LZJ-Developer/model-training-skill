# 虚拟细胞扰动预测：任务与评测契约

用于从数据整理、训练到最终报告的扰动响应预测。维护者的长期目标是**未见背景 + 未见扰动的联合外推**；面向这一目标时，单轴结果只能提供局部证据。用户明确要求单轴任务时，按该任务交付，不额外强制双未见实验。以下是评测设计要求；论文结果仅支持其实际测试范围，不是模型优劣的普遍定律。

## 1. 先写清预测对象与可见信息

任务卡至少固定：背景定义、扰动定义、输入、输出、训练/部署可见信息、允许的外部知识、主要评价量与结论范围。缺少会改变实验含义的信息时先对齐；无关字段可以保留未定，不先下载大数据或扩算力。

- **背景 `c`**：拆开 donor、cell type、cell line、组织、实验批次/平台与培养条件。留出某个 `(donor, cell type)` 组合不等于两个因素都未见；新 batch 也不自动等于新生物背景。报告各因素 seen/unseen 状态及混杂。
- **扰动 `p`**：记录靶点/分子、CRISPRi/a/KO/药物等机制、guide/construct、组合、剂量和时间。未见 guide 不一定是未见靶点；未见组合不一定是未见成分；剂量/时间插值与范围外外推分别报告。组合任务注明 zero-/one-/two-seen 成分，不把它们合并。
- **部署输入**：是否允许目标背景的 non-targeting control、细胞组成、已知注释或适配数据？允许 control 的任务应描述为“在目标 control 条件下外推响应”；没有该输入时不能在评测中补给。control 的使用方式和预算对比较方法一致。
- **扰动可识别性**：新扰动怎样进入模型？序列、分子结构、已知靶点、PPI/功能嵌入，还是只用训练 ID？若所有新 ID 都落到同一 unknown token，且其他输入相同，确定性模型无法区分它们；先补可部署的表示或收窄目标，增加参数不能凭空创造身份信息。
- **输出**：明确是 counts、变换后的平均表达、相对匹配 control 的效应 `Δ`，还是条件分布 `P(X | c,p,dose,time)`。通常的 scRNA-seq 是未配对群体测量；没有真实配对证据时，不能把任意 control/treated 细胞配对当作同一细胞的前后真值。[未配对扰动建模原始论文](https://ojs.aaai.org/index.php/AAAI/article/download/39190/43151)

Arc 官方 VCC 将目标 context 的 control 与响应外推明确区分，体现了“是否有目标 control”会改变任务本身；具体年度规则需在运行时核对。[官方任务说明](https://arcinstitute.org/news/virtual-cell-challenge-2026)

## 2. 四象限与真正的双未见

`seen` 相对于该次模型可用的**响应训练/evidence 语料**定义，并审计预训练覆盖。测试条件自身的真实响应不能作为输入。

| 测试面 | 背景响应训练中出现 | 扰动响应训练中出现 | 回答的问题 |
|---|---|---|---|
| 见背景、见扰动 | 是 | 是 | 已知因素的新样本或留出的因素组合；若同一条件也出现，只是条件内预测 |
| 留背景 | 否 | 是 | 已知扰动能否迁移到新背景 |
| 留扰动 | 是 | 否 | 已知背景能否预测新扰动 |
| **双未见** | **否** | **否** | 新背景与新扰动相遇时能否预测 |

两个单轴测试成功，不能推出双未见成功：模型可能分别记住背景相关响应和扰动相关响应，却无法处理其交互。主目标为双未见时，必须保留对应的联合测试面，不能只随机留 `(c,p)` 配对。

划分先按实验设计和实体等价类确定，再生成细胞/监督行列表。双未见主任务中，背景与扰动都要分别建立 train、validation、final-test 的隔离集合；其他象限按各自目标保留已见因素。最终测试的双未见状态应相对于**所有实际用于拟合的开发语料**复查，包括后续合并进训练的 validation。随机单细胞划分可回答条件内问题，但不能据此宣称跨背景或跨扰动泛化。

## 3. 三层数据边界与泄漏审计

1. **Train** 拟合模型参数，以及数据驱动的 HVG、缩放、分箱、响应先验和 evidence。每个 fold 重建响应派生缓存。数据处理细节见 [data-cleaning.md](data-cleaning.md)。
2. **Validation** 用于 checkpoint、超参、阈值和方法选择；其设计应反映主目标。验证反馈使用次数/预算需要记录，避免将大量选择后的最高分当无偏估计。
3. **Final test** 在配置冻结后评价；其响应不用来选 checkpoint、HVG、阈值、幅度或 evidence，也不用于挑选要报告的子集。预先允许的目标 control 可以作为输入，但不能扩大成目标扰动响应或未声明的适配。只要根据最终响应修改方案，该数据即成为开发数据，新的外推结论需要另一个未使用测试面。

校准另写清“参数估计”与“方案选择”：参数可在预先指定的训练内交叉拟合或开发校准分区估计，方案在相应验证证据上选择。若使用 validation 标签拟合幅度或其他校准参数，该部分就是校准开发数据，拟合后的分数不能再当独立验证成绩；可交叉拟合或另留验证数据。最终测试响应不参与任何一种校准。

跨语料审计同时覆盖实体和测量：gene/药物别名、细胞系标识、同一实验重发布、相同响应的不同聚合版本，以及检索库/教师预测/evidence 的数据来源。报告重叠类型、数量、处置和无法核实项；不能把字符串无交集当无泄漏证明。

区分**身份/机制先验**与**响应答案**：部署时可得的 PPI、序列、已知药物靶点不因包含测试实体就自动违规；由测试响应计算的靶点统计、目标背景响应缓存则可能越界。预训练语料包含什么需要单列；未知覆盖记为未知，不能据此宣称“所有训练语料严格未见”。允许相关预训练响应时，应改写为相应的迁移设定，并与严格未见实验分开。

泄漏探针在独立诊断副本上运行：改变留出响应后，比较训练侧特征、拟合参数和 evidence 是否变化；结合来源审计、实际索引断言和缓存重建。有限哨兵/NaN 可能被裁剪或吞掉，单次探针阴性不是无泄漏证明。标签置换的效果只在同样独立留出上解释；高容量模型拟合随机训练标签可以是正常记忆，不要求其训练失败。

## 4. Baseline 要和模型回答同一任务

先固定同一信息集合，再比较能力；新增外部信息的价值另设信息增量实验，不能混入“架构改进”的归因。

| Baseline | 适用与限制 |
|---|---|
| 无变化：预测匹配 control / `Δ=0` | 检验背景与弱效应是否已解释分数；不能偷偷使用部署不可得的目标 control |
| 训练均值/平均扰动响应 | 只用允许的训练语料；目标条件实测均值是 oracle，不能伪装成可部署 baseline |
| 线性/岭回归或低秩模型 | 输入同样可得的背景、扰动表示；未知扰动不能使用不存在的独热系数，正则在 validation 选 |
| 加性组合：`Δ(a+b)=Δ(a)+Δ(b)` | 标明单扰动响应是否可用；只在组合任务及同一信息预算下比较 |

所有方法共用 split、基因集合、表示/单位、目标 control 规则、evaluator 和合理的选择预算。预训练贡献可通过可行的随机初始化/冻结/替代表示对照检验，不把单一对照的无显著差异解释成所有预训练均无用。模型未超过强 baseline 时，允许交付负结果；只有要宣称优越性或继续扩算力时，才需新的证据支持。

简单 baseline 在多项已发表 benchmark 中具有竞争力；这是要求比较的实证理由，不是禁止复杂模型。[Nature Methods 原始比较](https://www.nature.com/articles/s41592-025-02772-6)、[Systema 原始研究](https://doi.org/10.1038/s41587-025-02777-8)

## 5. 输出目标决定评价量

| 预测/主张 | 必需的对齐检查 |
|---|---|
| counts 或平均表达 `μ` | 相同库大小、基因集合与变换上的误差；pseudobulk 均值可以是有效目标，不能仅因是均值就否定 |
| 效应 `Δ=μ_pert−μ_control` | control 匹配与误差传播；方向、幅度与相对 baseline 的改善；只看全表达相关性容易被背景支配 |
| DE/扰动区分 | 固定 DE 方法、独立重复、检验基因、阈值和多重校正；分别报告 DE 恢复及扰动身份区分，说明是否排除直接干预靶基因 |
| 细胞分布/异质性 | 与主张对应的分布距离、状态比例、方差/协方差等；均值和逐基因 DE 指标不能单独证明恢复联合分布 |

若训练在 `Δ` 而提交在抽样 counts 上评分，记录渲染链、抽样假设及两层指标，在 validation 按预设主目标选模型。报告逐 perturbation/context 指标、宏平均和失败组；复合分数同时给分量、方向、归一化与权重，不把单项改善写成全面提升。systematic variation 可令常见指标失真，必要时加均值响应等诊断 baseline。[Systema](https://doi.org/10.1038/s41587-025-02777-8)

评价器也属于实验定义：固定实现版本/commit、metric 配置、归一化、基线锚点、基因排除与聚合规则。官方 `cell-eval2` 的版本变更实际涉及指标与 baseline 重算；不能只凭相同指标名横比不同口径。[官方代码与变更记录](https://github.com/ArcInstitute/cell-eval2/blob/main/CHANGELOG.md)

## 6. 不确定性来自什么单位

- 监督行、细胞和独立生物学重复是三个概念。根据目标总体和实验随机化识别 donor、独立培养/动物等单位；技术文库、多个 guide 或同一 donor 的细胞不自动增加独立生物学重复。
- 两臂在同一留出条件配对比较，重采样/层级模型尊重 donor、实验和复用 control 的依赖。汇总总体是 perturbation 集还是 donor 总体需说清，不能把每个表达标量当独立观测。
- 多种子刻画优化/抽样随机性；跨生物学重复的变异刻画实验与个体差异。前者不能替代后者；缺独立重复时仍可报告有限数据集上的误差与种子变异，但不能给出跨 donor 推断的假精度。[伪重复实证](https://www.nature.com/articles/s41467-021-21038-1)
- 阴性或不可区分结论注明配置、信息范围、预算与区间；一次结构探针或单种子阴性不证明方法方向不存在价值。

## 7. 交付与结论边界

与通用运行产物一起保留：任务卡；数据/预训练/evidence 来源及重叠审计；有序 gene/cell/condition 和 split 清单及 hash；QC/变换的 fit 范围；代码、环境、checkpoint、训练与渲染 seed；evaluator 版本及配置；逐条件预测、baseline、分量和不确定性；最终测试使用记录及未决项。受数据许可限制时保存可追溯引用与重建方法，不发布受限原始数据。

结论只覆盖已测任务和信息条件。预测关联、机制解释、因果机制与实验验证分别陈述；扰动 benchmark 成绩不能直接升级为药效、患者获益或临床有效性结论。脱敏案例只用于理解工程取舍，不能充当该次训练的独立复现证据，见 [案例](case-study-perturbation.md)。
