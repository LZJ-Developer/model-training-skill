# 改动自查：HTCA 与信息路径

这里保留 HTCA、BBOC 作为维护者组织问题的标签。它们是**可选自查提示**，不替代任务契约、四道检查或实证比较，也不是新颖性/可发表性的判决器。无需先给所有轴分类，才能开始低成本检查。

本文件不再转述未经核验的内部备忘历史或引语；不把语言模型的扩展结果当作虚拟细胞任务的证据。

## 1. HTCA：用四个视角描述改动

| 视角 | 可问的问题 | 候选检查 |
|---|---|---|
| H：依赖与表达 | 哪些输入可以影响哪些输出？相同依赖集合下，函数参数化是否变化？ | 计算路径、函数约束、合成可解任务和容量对照 |
| T：学习目标与样本构造 | loss、正则和训练样本如何推动目标行为？ | 训练/部署信息表、梯度贡献、对应关系消融 |
| C：计算与实现 | 分块、共享、精度或压缩如何影响资源与结果？ | 同任务下的耗时、显存、数值误差及性能对照 |
| A：信息获取与利用 | 信息来自哪里？预先提供还是模型主动选择？部署能否获得？ | 来源审计、可用性、获取成本和去除该信息的对照 |

这些视角可以重叠：正则会改变学习行为，低秩约束可能同时改变计算和可表达函数；相同依赖边不保证相同表达能力。预先准备外部特征应写成信息利用，主动检索/实验选择应说明决策机制；命名差异不决定科学价值。

用法：写清“改了什么、为什么可能影响某个指标、哪个检查能推翻该解释”。暂时没有机制证据时，把它标为假设，而不是判定“没有改动”或补写一个确定机制。

维护者案例中的跨基因分支、模拟部署训练、共享记忆和扩充背景，可以作为提出候选实验的例子；其适用范围与脱敏证据边界见 `case-study-perturbation.md`。

## 2. 三个有用的问题

### 2.1 所需信息能影响输出吗？

先审计数据、缓存、前向代码和条件分支，再做梯度与有限干预。对模型 `y = f_theta(x, z)`，局部 Jacobian `∂y/∂x` 描述的是**当前参数、当前输入附近的敏感性**，不是整个函数类是否具备某条依赖的证明。

几个反例：

- `f_w(x) = w*x` 在 `w=0` 时对所有 x 都有 `∂f/∂x=0`，但 `∂f/∂w=x`，训练可以让 w 离开零。
- ReLU 的未激活区、饱和、掩码及多个输出求和的抵消，都会产生局部零梯度。
- `1[x>0]` 等离散函数可依赖 x，但几乎处处导数为零；整数 ID 也不适合直接用输入梯度测试。

因此应：

1. 在多个有效输入、输出分量或随机投影上检查梯度，避免只看输出和。
2. 对离散变量做替换/删除，对连续输入做不同尺度的有限干预；保持其他输入、随机性及缓存一致。
3. 零初始化分支按“初始化恒等性 → 有效更新 → 激活后依赖”检查，见 `diagnostics.md` §2。
4. 对所测结果保留限定：“在这些输入和状态下未发现影响”。只有代码/数学分析支持**所有允许状态均不使用 x**时，才能断言该固定架构不直接条件化于 x。

结构上没有该输入路径时，仅延长训练不会凭空新增路径；但训练仍可能借其他输入改善性能，改变架构也可能引入路径。不能由一次零梯度推导“增加任何算力都无效”。

自动微分记录实际执行的计算，非光滑与不可微操作有各自规则，参见 [PyTorch Autograd mechanics](https://docs.pytorch.org/docs/stable/notes/autograd.html)。

### 2.2 信息经过压缩后还够用吗？

低秩、少量 latent token 或分块可能形成瓶颈，也可能提供有效正则或效率收益。若线性残差为 `U*V*x` 且中间维度为 r，其线性映射秩至多为 r；该结论不能直接推广到任意非线性、多层或带旁路的模型。

输入扰动引起的输出变化衡量**敏感性**，不是信息论带宽，也不证明信息有用。数值变化很大可能只是噪声放大，变化很小可能仍足以改善任务。

在固定任务与验证层下比较秩、slot 数或分块的容量/资源曲线，并结合目标信号、噪声、有效对照和分组性能。未观测到增益时，区分容量、优化、信息冗余及评测不敏感，不能直接判定“压缩丢掉了信息”。

### 2.3 训练提供的信息与部署要求匹配吗？

分别列出：

- 训练、验证、最终测试和部署可用的输入、标签、control、检索库及外部知识；
- 所需预测对象，以及未见背景、未见扰动或二者联合未见的泛化面；
- 样本、批次、背景/供体和扰动在各层的切分与依赖。

训练使用标签计算 loss 是监督学习的正常部分；蒸馏、增广或教师信息也不必与部署完全同构。需要检查的是：部署缺少的信息是否被错误当作推理输入、代理目标能否支持部署行为、验证是否真实模拟了允许的信息边界。

按背景分组的训练可以帮助某些集合目标，但不是所有扰动预测模型的必要条件。独立逐行模型也可能学到背景差异；需用实际目标、采样方式和对照验证，不能因没有同批多个扰动就断言“学不会可区分性”。

## 3. 覆盖、计算与证据边界

- 增加独立 donor/背景可能补充外推所需经验，增加同一背景的细胞可能提高测量精度或揭示稀有状态；具体收益取决于任务与采样，不能一概排序。
- 训练步数、batch、基因/序列长度、可训练参数量与实际计算不是同一量。`步数 × batch × 序列长度 / 参数量` 不是通用算力量；实际成本按 `recipes.md` 的代表性 profile 估计。
- 语言模型的参数/token 扩展规律、重复语料经验与涌现讨论不能为当前生物任务提供确定阈值。当前任务需要自己的数据规模、覆盖、容量和学习曲线证据。
- 未见背景、未见扰动与联合未见是不同主张；一个面上的改善不自动支持另一个面。具体契约由 `SKILL.md` 统一定义。
- 多项改动的整体收益与各部分贡献分开陈述，归因以 `run-artifacts.md` 的因子实验或消融为准。

目标是把“可能值得尝试”转成可检验、可负担的实验，而不是用框架名称替代证据。
