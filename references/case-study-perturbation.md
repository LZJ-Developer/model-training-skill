# 案例：扰动响应预测

一个完整的应用案例——从 PIE 式跨基因证据网络出发，预测未见细胞背景下的基因与药物扰动响应。本文件只放**在这个任务上被实测或实测推翻过**的东西；通用方法看 `SKILL.md` 与另外几份 references。

案例的价值不在于数字好看，而在于**每一条结论都付过学费**：哪些方向做之前看起来合理、做完是负的，以及怎么在花算力之前就知道。

> 本案例只给**相对量**：比值、占比、倍率、数量级。绝对分数与数据规模已去除，但它们之间的相对关系足以复现全部判断。

---

## 1. 监督单元

- 一条监督行 = (数据集, 背景, 扰动)。可用公开语料合计在**十万行量级**。
- 每行是一个基因向量（`delta_p`，`log1p(CP10k)` 的组均值差），配 `tested` 布尔掩码。
- **独立样本是行，不是标量。** 标量总数比行数大三个数量级以上，不能拿来算参数/样本比。
- `delta_p` 的目标是折 change 分箱的 one-hot（两热编码），分箱宽度取 `ln(1.1)`（约 10% 的倍数）。这个 head 是**按值的分箱**，与基因轴无关，所以换语料不改 head 尺寸——**前提是把分箱上界显式固定成训练时的值**；让它按新语料的分位数重新拟合，head 尺寸就变了，warm-start 直接失效。

---

## 2. 数据契约（G0 的本地版本）

1. **`tested` 掩码始终生效。** 未测 ≠ 零效应。所有损失项、所有聚合统计都要乘掩码。全被掩码的行要在求均值前剔除（这是 NaN 的常见来源）。
2. **尺度必须对齐。** 不同语料的平均 |Δ| 相差约 **3 倍**；on-target 敲低强度相差 **一个数量级以上（约 16 倍）**。不对齐就直接混训，模型学到的是「这个数据集整体被缩小了 3 倍」。
3. **背景均衡权重。** 按 (模态, 背景) 归一化后等权。否则单一语料占据 **90% 以上**的显著标签数，会吞掉其他模态的梯度。
4. **靶基因剔除按模态分支。** 基因模态要剔除扰动基因自身；药物模态没有「自身基因」，遮罩逻辑不同。
5. **只有 ≥2 个背景的靶标进入迁移损失。** 单背景靶标对迁移项没有梯度意义，只会贡献噪声。

---

## 3. 泄漏

- **evidence 必须按 fold 重建。** 框架的 evidence 缓存会把训练集的响应统计当作**输入**。留出背景的任何响应行进入 evidence，就是把答案喂进模型。每个 fold 重建，并断言 evidence 的 (扰动, 背景) 与测试集无交集。
- **框架自带的泄漏检查只覆盖 evidence donor。** 它**不覆盖** esm2 / STRING / depmap 这类外部知识源。一旦接入任何靶标级统计量（按靶标聚合的响应先验等），必须自己补一层审计，否则会从知识源这条侧路泄漏。
- 检查手段：把目标随机打乱重训，看指标是否仍高于基线。更强的一种是 `diagnostics.md` §5.1 的 NaN 染色——往留出背景的响应行注入哨兵值（`1e12`，不是 NaN，因为 `nanmean` 会吞掉它），跑真实管线，看它有没有污染训练侧的量。这能把「断言两集合无交集」升级成「证明没有路径」。

---

## 4. 新增分支的验证

跨基因 evidence 分支（少量 slot 读全组 evidence，零初始化残差回写 decoder 某一层）在接真 checkpoint 前跑了四项检查，全部通过：

| 检查 | 结果 | 说明 |
|---|---|---|
| 恒等性 | `max abs diff = 0.000e+00` | 零初始化时输出与原模型逐位相同 |
| 梯度 | 输出层梯度非零、量级正常 | 分支会离开零 |
| 路径 | 改一个基因，其他基因移动的幅度约为被改基因自身的 **1/300** | 信息确实跨基因流动，且不是复制 |
| 载入 | strict load OK，新增参数量在 **1e7 量级** | 与已有权重兼容 |

**一个必须记的工程细节**：把 evidence 融合从 chunk 循环里提到循环外。原因是融合里有按行采样的 dropout 掩码，逐 chunk 融合会在 eval 里**无声地**重新采样不同的掩码，导致同一个样本的两次推理结果不同。这类 bug 不报错，只让结果不可复现。

**参数/样本比**：完整 Transformer 块形式约为 **100:1 以上**（超过经验上限约 4 倍）；去掉 FFN 后约为 **30:1**（刚好在上限）。这是选择小版本的唯一理由——不是「小模型更好」，是「这个比例下大版本是高风险动作」。

---

## 5. 读数层与评分层

- 训练在 `delta_p` 空间；评测在**渲染后的 counts** 上算。中间隔着负二项抽样 + Dirichlet-multinomial。
- 所以损失对齐是「通过已知非线性变换」，不是直接优化。写方法时必须这么写。
- **两层的排序可以相反**，已多次实测：
  - 某次改动读数层误差明显改善，六项均值只拿到总提升的 **约 6%**；
  - warmdown 让评分层下降，幅度约等于此前最佳提升量的 **40%**，同时读数层的相关系数反而上升；
  - 步数曲线上读数层在**较早的**步数最好，评分层在**更晚的**步数最好。
- **规则：任何 checkpoint 选择、超参选择、幅度系数选择，一律按评分层。**

---

## 6. 报告分量向量（实例）

某次改动的六项分解，全部按相对量表述（把六项均值的提升记为 1.00）：

| 来源 | 对总提升的贡献 |
|---|---:|
| 其中一项（伪 bulk 精度类） | **≈ 0.95** |
| 其余五项合计 | **≈ 0.05** |
| 其中「扰动可区分性」这一项 | **下降约 1/3** |

**结论**：这次改动的全部内容是「修好了那一项」。如果对外主张是「扰动可区分性 / DE 召回」，那这个进步不成立——被优化目标之外的那一项反而明显变差。

对外材料里不得把这种复合分数的提升写成「预测能力提升」。

---

## 7. 零对照（踩过的坑）

跨模态结构探针的第一版用**行置换**做零对照，得到与真实对照**完全一致**的结果（三位小数相同）。原因是：右奇异向量对行置换不变——`P·X = (P·U)ΣVᵀ`，`V` 完全不变。这个零对照在数学上等于真实对照。

修正后的零对照，全部相对同株配对归一：

| 零对照 | 相对值 | 含义 |
|---|---:|---|
| 同株：跨模态配对 | 1.00 | 参照 |
| 异株：同模态无关配对 | **≈ 1.00** | 与同株相同 → **没有细胞系特异性** |
| 基因轴打乱 | ≈ 0.27 | 结构确实是基因级的 |
| 随机子空间 | ≈ 0.12 | 绝对下限 |

**判读**：跨模态共享结构存在（约为随机子空间的 **8 倍**），但不是细胞系特异的。所以对外只能说「共享响应基 + 模态条件化」，**不能说「跨模态迁移」**——后者要求同株配对带来额外增益，数据显示没有。

---

## 8. 已判负，不要重试

| 方向 | 结论 |
|---|---|
| 输出幅度后校准（同靶标实测均值） | 增益的 **90–97%** 来自一个全局收缩系数，逐扰动只贡献 **0.1–1.3%** |
| DE 概率校准 | 训练折最优阈值在留出集无增益 |
| 背景相似度加权（用 control 表达相似度定权重） | ≈ 等权 ≈ 随机，四折全部变差；背景两两相似度高到无法区分 |
| 网络先验收缩（STRING） | 增益几乎全部来自「混入公共敲低程序」，网络特异部分接近零 |
| 逐基因「方向取一个模型、幅度取另一个」 | 内部排序不如原模型，排序相关系数显著下降 |
| 逆模型 / 跨背景检索 | 两个未训练背景的预测几乎完全重合，靶标判别在任何预算下失效 |

---

## 9. 发布门槛

- **平凡基线是门槛不是优化项。** 闭式岭回归基线在同样的留出集上出数，模型不超过它就不该发布。
- **随机初始化底座对照必须做一次。** 有报告全量微调的预训练模型与随机初始化无显著差异；不测，无法把贡献归因到底座。若两者无差异，叙事必须改。
- 打不过简单基线时的正确动作：改做数据侧，或如实报告负结果。不是继续调参。

---

## 10. 环境约定

- 大数据放在独立的数据盘（`<DATA_ROOT>`），仓库与 home 只放代码和小文档，不要用 `/tmp` 存大文件。
- 上游框架保持只读；所有改动放自己的目录，或以 patch 形式维护。
- 跑框架 CLI 前把它的路径类环境变量显式设全（数据根、运行根、缓存目录）。缺一个会静默解析到少一层的路径。
- `PYTHONPATH` 按命令注入，不要全局 export；评测器常常跑在另一个 Python 版本的 venv 里。
- 日志里的 `Epoch N: x/<N>` 是 batch 数，不是优化步；有梯度累积时 `global_step ≈ batch / accum`。判断进度只认 checkpoint 里的 `global_step`。
