# 案例：扰动响应预测

维护者提供的脱敏工程案例：从 PIE 式跨基因证据网络出发，探索未见细胞背景下的基因与药物扰动响应。它保留值得复用的经历，不是通用最佳参数或独立 benchmark。

> **证据边界**：下文数字与运行结果均为维护者自述，当前 skill 审查未独立复核原始数据、代码、日志或 checkpoint。相对量经过脱敏，可解释取舍，**不足以复现全部判断或验证因果归因**。本次维护不要求提供真实数据；将来有授权证据时可逐项更新核验状态。

本案例主要涉及留背景；未报告足够信息确认所有实验满足“背景与扰动同时未见”。新项目的完整任务、划分和评价规则以 [perturbation-evaluation.md](perturbation-evaluation.md) 为准。

---

## 1. 监督单元

- 一条监督行 = (数据集, 背景, 扰动)。可用公开语料合计在**十万行量级**。
- 每行是一个基因向量（`delta_p`，`log1p(CP10k)` 的组均值差），配 `tested` 布尔掩码。
- 一行是一个监督对象，**不自动是独立样本**：不同的行可共享 donor、实验、靶点或 control。表达标量总数比行数大三个数量级以上，也不能作为独立样本数；需另报背景/扰动/独立生物学重复的覆盖与依赖。
- 案例用按值分箱的 head，分箱宽度为 `ln(1.1)`，并报告使用“两热编码”（具体插值规则待实现核验）。`delta_p` 是 log1p 表达的均值差，不应无条件称为严格 log fold change。head 不按基因数扩展；warm-start 时须固定分箱数量、边界及溢出规则。按新语料重新拟合分位数可能改变标签语义；只有 bin 数变化时才必然改变 head 尺寸。

---

## 2. 数据契约（G0 的本地版本）

1. **`tested` 掩码始终生效。** 未测 ≠ 零效应。监督损失和对应聚合统计遵守 tested 范围；不能只把 NaN 乘零当有效遮罩。全掩码行在求均值前显式处理，避免分母为零。
2. **检查尺度来源。** 案例报告不同语料平均 |Δ| 相差约 **3 倍**、on-target 敲低强度约 **16 倍**。差异可能包含单位、测量和真实生物效应；不能仅凭比例断言模型学到了数据集身份。校准系数从允许的训练数据估计，并保留未校准对照。
3. **权重是一项选择。** 案例按 (模态, 背景) 归一化后等权；单一语料原占 **90% 以上**显著标签。该比例提示失衡，但不单独证明它支配梯度；可结合各组损失/梯度和替代加权对照判断。
4. **靶基因遮罩按任务声明。** 案例在基因模态某些指标中排除直接干预靶基因，药物模态另设规则；不能推广成所有损失/指标都必须排除。区分直接敲低与下游响应，并报告对应口径。
5. **迁移损失的可计算条件。** 案例所用跨背景配对项只纳入 ≥2 个背景的靶标；这依赖该损失的定义，不等于单背景靶标对所有训练目标都无用。

---

## 3. 泄漏

- **响应 evidence 按 fold 重建。** 案例把响应统计作为输入，留背景时不能混入该背景的响应；双未见还须隔离留出扰动在其他背景的响应。既检查背景/扰动轴，也检查具体来源行，不能只断言 `(扰动, 背景)` 配对不重叠。
- 案例自带检查据维护者说明只覆盖部分 evidence 来源；esm2、STRING、DepMap 等各自需要溯源。序列/PPI/已知靶点作为部署可得先验不自动违规；由被留出响应派生的统计或等价实验重发布才需按契约隔离。预训练覆盖未知时不能声称全部语料严格未见。
- 泄漏检查使用独立诊断副本及独立留出：改变留出响应，比较训练特征、evidence 与拟合量；结合索引断言和缓存重建。`NaN` 可被 `nanmean` 吞掉，有限哨兵也可被裁剪/过滤，不能用一次阴性探针证明没有路径。打乱标签后检查**留出表现**；随机训练标签被高容量模型拟合不等于泄漏，不要求随机标签训练失败。

## 4. 新增分支的验证

维护者报告：跨基因 evidence 分支（少量 slot 读全组 evidence，零初始化残差回写 decoder 某一层）做过以下检查。它们检查实现行为，不独立证明泛化收益；具体探针状态与日志尚待核验。

| 检查 | 结果 | 说明 |
|---|---|---|
| 恒等性 | `max abs diff = 0.000e+00` | 零初始化时输出与原模型逐位相同 |
| 梯度 | 输出层梯度非零、量级正常 | 存在局部学习信号；仍需检查实际更新与分支激活 |
| 路径 | 改一个基因，其他基因移动约为自身的 **1/300** | 此探针中观察到跨基因影响；量级本身不证明有用 |
| 载入 | strict load OK，新增参数量在 **1e7 量级** | 需核对所载 state_dict 的版本与新增参数初始化 |

**工程启示**：维护者将 evidence 融合移到 chunk 循环外，以避免自定义按行采样在不同 chunk 重采样。标准 Dropout 在 `eval()` 下应关闭；若评测仍随机，需定位自定义采样/模式传递等真实来源，而不是把所有 chunk 融合视为有 bug。比较 chunk 划分、重复推理和共享随机源。

**容量取舍**：案例按监督行计算的参数/行比，完整 Transformer 块约 **100:1 以上**，去掉 FFN 后约 **30:1**，因此先试较小版本。这是本项目预算下的启发式选择；监督行并非全部独立，不能由这些数字推出通用上限。扩容价值应由验证曲线、正则化与可用信息覆盖检验。

## 5. 读数层与评分层

- 训练在 `delta_p` 空间；评测在**渲染后的 counts** 上算。中间隔着负二项抽样 + Dirichlet-multinomial。
- 训练损失不直接等于提交指标；方法中需描述渲染链及随机性，不能把两层混写成同一目标。
- **两层排序可相反**，维护者报告多次观察到：
  - 某次改动读数层误差明显改善，六项均值只拿到总提升的 **约 6%**；
  - warmdown 让评分层下降，幅度约等于此前最佳提升量的 **40%**，同时读数层的相关系数反而上升；
  - 步数曲线上读数层在**较早的**步数最好，评分层在**更晚的**步数最好。
- **案例启示**：checkpoint、超参和校准方案按预先声明的验证目标选择，同时保留读数层诊断；幅度等校准参数在指定开发分区估计，拟合后分数不能当独立验证，见任务与评测契约 §3。最终测试只评冻结方案，不参与任何选型。

## 6. 报告分量向量（实例）

某次改动的六项分解，全部按相对量表述（把六项均值的提升记为 1.00）：

| 来源 | 对总提升的贡献 |
|---|---:|
| 其中一项（伪 bulk 精度类） | **≈ 0.95** |
| 其余五项合计 | **≈ 0.05** |
| 其中「扰动可区分性」这一项 | **下降约 1/3** |

**可保留的解读**：按案例所用聚合口径，改善主要来自伪 bulk 精度分量，扰动区分分量反而下降；不能写成各能力全面提升。贡献比例依赖尺度、权重与参照值，不单独建立机制归因；原始分量和不确定性缺失时也不能判定 DE 召回显著改变。对外可准确写明被测目标及分量变化。

## 7. 零对照（踩过的坑）

跨模态结构探针的第一版用**行置换**做零对照，得到与真实对照相同的结果（三位小数）。原因是对置换矩阵 `P`，`(PX)ᵀ(PX)=XᵀX`，右奇异子空间不变；单个向量仍可因符号或重奇异值选择而变化。若统计量只依赖这个子空间，行置换没有打掉其检测对象。

修正后的零对照，全部相对同株配对归一：

| 零对照 | 相对值 | 含义 |
|---|---:|---|
| 同株：跨模态配对 | 1.00 | 参照 |
| 异株：同模态无关配对 | **≈ 1.00** | 此探针未显示同株的额外优势 |
| 基因轴打乱 | ≈ 0.27 | 提示统计量依赖基因对应，尚非机制证据 |
| 随机子空间 | ≈ 0.12 | 该构造下的随机参照，非普遍理论下限 |

**判读边界**：案例结构相似度约为随机参照的 **8 倍**，但匹配细胞系未显示额外优势。它可提示一般共享结构及探针是否保留了基因对应，不能单独证明或否定跨模态迁移，也不能确认没有细胞系特异信号。迁移收益需要在明确的未用响应留出面上比较有/无跨模态信息，并给出不确定性。

## 8. 本配置中的负结果与重试依据

以下是维护者报告的局部结果；其适用边界是当时的数据、实现、预算、划分与指标，未独立复核。只有提出不同机制、修正实现、补充覆盖或使用新评价目标等具体依据时，再安排相应对照；不将一次失败升级为永久禁用。

| 方向 | 结论 |
|---|---|
| 输出幅度后校准（同靶标实测均值） | 增益的 **90–97%** 来自一个全局收缩系数，逐扰动只贡献 **0.1–1.3%** |
| DE 概率校准 | 训练折最优阈值在留出集无增益 |
| 背景相似度加权（用 control 表达相似度定权重） | ≈ 等权 ≈ 随机，所测四折均变差；高背景相似度是待验证的解释 |
| 网络先验收缩（STRING） | 案例分解与公共响应成分解释一致，网络特异部分接近零；尚不足以确定科学机制 |
| 逐基因「方向取一个模型、幅度取另一个」 | 内部排序不如原模型，排序相关系数下降；显著性尚待核验 |
| 逆模型 / 跨背景检索 | 两个未训练背景的预测几乎重合，所测试预算中未获有效靶标判别 |

## 9. 支持什么结论

- **优越性需要同任务 baseline。** 无变化、训练均值、可用输入下的线性/岭回归等在同一留出集比较；组合任务按信息条件加 additive。未超过 baseline 时可以发布负结果，不能宣称更优；继续训练需要具体新假设与预算理由。[简单 baseline 的原始比较](https://www.nature.com/articles/s41592-025-02772-6)
- 若主张贡献来自预训练，需要可行的随机初始化或替代表示对照及相应预算。无显著差异不等于等效，也不能推论所有预训练无用。
- 案例不构成跨 donor 或临床有效性证据；同一 control、donor 和实验造成的相关性、训练种子与生物学重复的不确定性分别处理，见 [任务契约](perturbation-evaluation.md)。

## 10. 环境约定

- 案例将大数据放在独立数据根（`<DATA_ROOT>`），改动在自己的目录或 patch 中维护。其他项目遵循其授权路径与存储约定，不照搬磁盘布局。
- 案例曾遇路径变量缺失而解析错误；运行前核对 CLI 实际解析的数据、运行与缓存根目录。不能据此假定所有框架都有相同错误。
- `PYTHONPATH` 按命令注入，不要全局 export；评测器常常跑在另一个 Python 版本的 venv 里。
- 区分 micro-batch、optimizer update 和框架 `global_step` 的具体定义，不能仅凭 epoch 进度推算有效优化步；核对累积、末批与跳步行为，并在 checkpoint/日志保存相应计数。
